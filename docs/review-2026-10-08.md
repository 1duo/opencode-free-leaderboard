# Review and execution record — 2026-10-08

The implementation was reviewed before running the saved public benchmark panel. This review improves the evidence and failure handling; it cannot establish absolute fairness or identify training contamination or silent changes behind provider aliases.

## Findings resolved

- Recovery now checks the same combined output bound as live execution. Missing usage or a cap overrun retains the response, prevents replay, and removes headline eligibility. A response saved before the job-state commit is recovered for local grading.
- Historical rows use the evaluation cycle's frozen endpoint and settings. Canonical question IDs remain stable when a grader revision reuses the frozen questions. Replacement seasons reuse questions, never answers.
- Explicit provider availability/configuration failures stop that model without assigning a capability zero. Saved generations can still be graded after an endpoint becomes unavailable.
- Publication checks tracked and staged paths against an allowlist. Public snapshots and manifests contain aggregate scores and IDs/hashes, without prompts, answer keys, raw responses, private filesystem paths, or credentials. Invalid staging preserves the prior export.
- Actual Docker validation exposed unreadable upstream files for the non-root grader. The image now makes its pinned sources readable. Official LiveBench correct/incorrect fixtures, LiveCodeBench correct/incorrect fixtures, and a nonterminating Python fixture were exercised in the running isolated container.
- Native OpenCode experiments have separate epochs and never enter headline rankings. They deny tools and auxiliary agents, select one exact verified free model ID, and reject tool use, multiple completions, nonzero reported cost, or unbounded output. A diagnostic that fell back to the default agent was excluded and conservatively accounted; it contained no benchmark question.

Targeted checks covered recovery, cap revocation, malformed native responses, token counting, fixed/nested panels, public export exclusion, historical settings, and failed-export preservation. The affected subset passed seven tests, and one additional regression checks that later weekly probes cannot alter a completed pilot's health evidence. Ruff and JavaScript syntax checks passed. This was not a full-suite run.
