Method

Custom subsets, not official benchmark leaderboard scores. Intervals use 10,000 stratified bootstrap resamples and reflect question sampling, not repeated-generation variability.

Unanswered requests remain unscored. Authorized recoveries are labeled; original attempts and token charges are retained.

GPQA requires explicit current no-training terms for the exact endpoint. Other routes use public benchmarks only.

Reasoning

GPQA and LiveBench contribute equally when both are present. LiveBench-only results use their LiveBench score and show that coverage explicitly.

Coding

LiveCodeBench Python pass@1. Each category uses the largest complete current panel for the model. Larger panels replace nested quick checks in this view.

Panels & protocol

Full screens use 20 GPQA Diamond, 20 LiveBench spatial / zebra questions (2024-11-25), and 40 LiveCodeBench Python problems (release_v6). Public screens use 20 LiveBench and 40 coding questions; quick checks use six per category. Sample sizes stay visible; partial panels and pilot answers have no category score. Historical runs and manual 240-question confirmations remain in the exports.

OpenCode version and highest exposed reasoning effort are recorded per model. One accepted completion per question, temperature zero where supported, a 4,096-token combined cap, frozen graders, and isolated grading. Native tool schemas are present; permissions are rejected and tool attempts score zero. No plugins or repair turns.

“Highest exposed” is the maximum selectable reasoning level in OpenCode. “Provider-managed” has no selectable level. The combined token cap applies; provider internals are unverified.
