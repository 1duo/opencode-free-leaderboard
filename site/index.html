03 / METHODOLOGY

A small panel. A clear protocol.

01

Fixed benchmark subsets

GPQA Diamond: 20 questions. LiveBench reasoning: 20. LiveCodeBench Python generation: 40. Confirmations expand these to 60 / 60 / 120 and reuse the original answers.

02

One completion, objective grading

No tools, repair turns, or answer selection. Temperature zero where supported, 4,096 generation tokens including reasoning where supported, with capped output verified in a pilot. Code is graded in isolated containers.

03

Separate capabilities

Reasoning equally weights GPQA and LiveBench. Coding is LiveCodeBench pass@1. The optional overall view defaults to 40% reasoning and 60% coding.

04

Dates and uncertainty stay attached

10,000 stratified bootstrap resamples and paired comparisons. LiveBench uses the verified 2024-11-25 spatial / zebra panel; LiveCodeBench uses release_v6. These are custom subsets, not official benchmark leaderboard scores.
