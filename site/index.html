Method

Custom subsets, not official benchmark leaderboard scores. Intervals use 10,000 stratified bootstrap resamples and reflect question sampling, not repeated-generation variability.

Panels

LiveBench spatial / zebra: 20 questions, dated 2024-11-25. LiveCodeBench Python: 40 problems, release_v6. Full screens also require 20 GPQA Diamond questions.

Protocol

OpenCode 1.18.31 with a fixed benchmark agent and its environment context. Native tool schemas are present; every permission request is rejected, and tool attempts score zero. No plugins or repair turns. Original benchmark roles; temperature zero where supported; 4,096-token combined cap. Frozen graders; isolated grading.

Full rankings & confirmations

Full screens contain 80 questions. Reasoning equally averages GPQA and LiveBench; coding uses LiveCodeBench pass@1. Overall defaults to 40% reasoning / 60% coding. Manual 240-question confirmations reuse the screen's 80 answers and stay in a separate ranking. Only complete panels receive ranks.

“Highest exposed” is the maximum selectable reasoning level in OpenCode. “Provider-managed” has no selectable level. The combined token cap applies; provider internals are unverified.
